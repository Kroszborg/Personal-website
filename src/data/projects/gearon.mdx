# GearOne - Smart Automobile Service Platform

## Overview

GearOne is a full-stack automobile service platform built to streamline vehicle servicing, bookings, tracking, and customer management through a modern mobile-first experience.

The project involved building not only the React Native application, but also the backend systems, admin panel, operational workflows, payment integrations, and production deployment pipelines for both Android and iOS.

The platform focused heavily on real-world operational workflows including service booking management, customer tracking, notifications, payments, and dashboard systems for internal operations.

## Key Features

### Cross-Platform Mobile Application

- Built using React Native with Expo for Android and iOS
- Responsive and optimized mobile UI with NativeWind (Tailwind for React Native)
- Real-time workflow updates and booking management via Supabase Realtime
- Authentication with email, Google Sign-In, and Apple Sign-In
- Multi-language support across English, Hindi, Tamil, and Telugu
- In-app push notifications via Expo Push Network

### Backend & API Infrastructure

- Developed Node.js/Express backend systems and REST API integrations
- Structured scalable service and order workflows with modular architecture
- Integrated customer and booking management with Supabase (PostgreSQL)
- Managed operational business logic, tracking systems, and Redis caching
- Swagger API documentation and health check endpoint

### Admin Dashboard & Operations

- Built a Next.js 15 internal admin panel for managing services and customers
- Tracking systems for service lifecycle management (bookings, vehicles, vendors)
- Dashboard with Recharts analytics for monitoring operational data
- Centralized management interfaces: bookings, users, vendors, offers, events
- Role-based access control with Supabase Row Level Security

### Payment & Transaction Systems

- Integrated Razorpay payment workflows for booking checkout
- Managed payment verification and transactional state synchronization
- Built reliable booking and payment state handling across mobile and backend
- Improved overall checkout and payment UX with real-time confirmation

### Deployment & Production Workflows

- Managed Android production build and Google Play Store submission
- iOS deployment via EAS Build and EAS Submit (no Mac required)
- Backend deployed on Render with auto-deploy from main branch
- Admin panel deployed on Vercel with automatic CI/CD
- Environment configuration, testing, and production readiness

## Tech Stack

- **React Native + Expo** – Cross-platform mobile development with file-based routing
- **NativeWind** – Tailwind CSS for React Native UI
- **Node.js + Express** – Backend infrastructure and REST APIs
- **Supabase** – Authentication, PostgreSQL database, and Realtime subscriptions
- **Next.js 15** – Admin panel with App Router
- **Razorpay** – Payment gateway integration
- **TypeScript** – Type safety across all codebases
- **Redis (Upstash)** – Optional caching layer for performance
- **Zustand + React Query** – State management across mobile and admin

## Technical Implementation

### Mobile Architecture

Built scalable React Native frontend architecture using Expo Router (file-based routing), managing navigation, state handling via Zustand and Tanstack React Query, and API communication via Axios with retry logic. NativeWind enabled Tailwind-style responsive UI. Multi-language support handled via i18n-js across four languages.

### Backend Systems

Designed modular Express API routes organized by domain (bookings, vehicles, vendors, payments). Integrated Supabase for authentication and Row Level Security policies across all database tables. Built service lifecycle tracking and Expo Push notification delivery via expo-server-sdk. Nodemailer for transactional email.

### Payment Integration

Implemented Razorpay payment workflows securely within the React Native app using react-native-razorpay. Backend webhook handling verified payment signatures and synced booking/payment state. Added transactional validation to ensure reliable checkout flows.

### Production Deployment

Configured Android builds using Expo's EAS Build with gradlew bundleRelease for Play Store submission. iOS handled entirely via EAS Build and EAS Submit without requiring a Mac. Backend on Render with auto-deploy; admin panel on Vercel with GitHub integration.
