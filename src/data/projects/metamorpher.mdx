# Metamorpher - 109 File Tools That Run in Your Browser

## Overview

Metamorpher is a free, open-source toolkit for working with files: PDFs, images, audio, video and documents. Every tool runs in the browser, so **your files are never uploaded**. There is no server for them to go to.

It began in 2025 as a single-screen file converter. In November 2026 I rebuilt it from scratch into 109 tools; none of the original source code remains. The full story is in [Rebuilding Metamorpher](/blog/rebuilding-metamorpher).

![The Metamorpher home page](/project/metamorpher-home.webp)

## Problem

Most online file tools upload your document to someone else's server. That is slow for large files and a real privacy cost for invoices, ID scans and contracts. The alternative is usually a paid desktop suite.

## Solution

Do the work on the visitor's own device. Modern browsers can run the same native engines a server would, compiled to WebAssembly, and they expose hardware video codecs directly. Metamorpher packages those engines behind one consistent interface.

## What it does

- **PDF:** merge, split (by pages, size, bookmarks or text), compress, rotate, crop, edit, sign, fill forms, redact, watermark, page and Bates numbers, encrypt, unlock, repair, compare.
- **Conversion:** Word, Excel, PowerPoint, EPUB, HTML, Markdown, CSV and text to PDF; PDF to Word, Excel, PowerPoint, HTML, EPUB, text and images.
- **Images:** convert, compress, resize, crop, HEIC to JPG, SVG to PNG, favicons, metadata removal, background removal, upscaling.
- **Audio and video:** convert, compress to a target size, trim, merge, mute, speed, rotate, resize, GIFs both ways, extract audio or frames.
- **Viewers:** CSV, JSON, Markdown, PDF, Office documents, images, media, archives, subtitles, fonts, SQLite, text and hex.
- **On-device AI:** OCR, transcription, summaries and chat with a document, or your own API key for a cloud model.
- **Everyday tools:** invoice generator, résumé builder with a LaTeX mode, whiteboard, QR codes, receipt maker, device-to-device file sharing.

## Architecture

### One registry, one folder per tool

Each tool is one registry entry (name, category, accepted types, search keywords) and one folder. Navigation, the home page, search, the sitemap and per-tool metadata are generated from the registry. Most tools share a workbench: dropzone, file list with progress, options, a run bar and results with a ZIP download.

### Engines

Every engine runs in a Web Worker and is loaded only when a tool needs it.

| Job | Engine |
| --- | --- |
| PDF structure | pdf-lib |
| PDF rendering, text, redaction, annotation | MuPDF (WebAssembly) |
| Encryption and repair | qpdf |
| Heavy PDF compression | Ghostscript |
| Image codecs | jSquash (MozJPEG, OxiPNG, WebP, AVIF), HEIC decoder |
| Video and audio | WebCodecs, with FFmpeg as fallback |
| OCR | Tesseract |
| On-device AI | ONNX Runtime with Hugging Face models |
| LaTeX | TeX Live compiled to WebAssembly |
| SQLite | sql.js |

All of them are copied from `node_modules` into the site's own static files at build time. Nothing is fetched from a CDN.

### Offline

A Serwist service worker precaches the application and caches each engine the first time it is used. After one visit, tools you have used keep working with no connection, and the site installs as an app on desktop and mobile.

### Optional accounts

Accounts add history and settings sync and nothing else. They are built with Better Auth, Drizzle and PostgreSQL (Neon), and the whole backend sits behind one switch so the site can run as a purely static toolkit. History stores tool names, never files.

## Privacy

- No third-party scripts, fonts or analytics services.
- First-party usage statistics count tool names only, with an off switch in the footer.
- The few features that contact another service (downloading an on-device model, a cloud model with your own key, the optional peer-to-peer helper) do so only when you choose them, and each is listed on the [privacy page](https://metamorpher.kroszborg.co/privacy).

## Testing

Before launch I ran every tool against the live site with real files. Two bugs existed only there, for returning visitors: a stale service worker that never installed, and a background-worker failure once it did. Both are fixed, and the test now runs once as a new visitor and once with the service worker in control.

## Limits

- Editing existing text inside a PDF is not supported yet; text, shapes, images and signatures can be added on top.
- Word to PDF is close to, but not identical to, Word's own output.
- Very large videos are bounded by the memory a browser tab is allowed.
- The LaTeX mode is pdfLaTeX without TikZ or BibTeX.
