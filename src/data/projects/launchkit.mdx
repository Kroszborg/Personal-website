# LaunchKit - AI Launch Copy Generator

## Overview

LaunchKit is an AI-powered web application that turns a GitHub URL or plain-text project description into launch-ready marketing copy — instantly, with no signup required.

Paste your GitHub repo URL or describe what you built, and LaunchKit generates a complete launch package: a landing page with headline, subheadline, feature bullets, and CTA; platform-specific social posts for Twitter/X, LinkedIn, and Product Hunt; plus a single-sentence perfect pitch ready for bios and cold emails.

Built with Next.js 15, Google AI SDK (Gemini), and the Vercel AI SDK for streaming responses, LaunchKit focuses on editorial quality output with a high-contrast dark design system.

## Key Features

### Landing Page Copy Generator

- Generates a complete landing page copy structure from your project description
- Includes: headline, subheadline, three feature bullets, and a call-to-action
- Output is launch-ready with no editing required

### Platform-Specific Social Posts

- **Twitter/X** – Concise, punchy post optimized for the 280-character format and developer audience
- **LinkedIn** – Professional narrative post with structured formatting for broader reach
- **Product Hunt** – Tagline + description optimized for the PH launch format and community

### Perfect Pitch Generator

- One-sentence product description engineered for bios, cold emails, and intros
- Captures what the product does, who it's for, and why it matters
- No filler language — sharp and specific output

### No Signup Required

- Fully functional without authentication
- GitHub URL support: fetches and parses the project README to extract context
- Results stream in real-time with a typewriter effect as the AI generates

## Tech Stack

- **Next.js 15** – App Router with Turbopack dev server for fast iteration
- **React 19** – Modern React with server components and streaming
- **TypeScript** – Strict typing throughout
- **Google AI SDK** – Gemini model integration via `@ai-sdk/google`
- **Vercel AI SDK** – Streaming responses and `useObject`/`streamText` patterns
- **Tailwind CSS 4** – Utility-first styling with the latest v4 architecture
- **Bun** – Fast package manager and runtime
- **Zod** – Schema validation for structured AI output

## Technical Implementation

### AI Streaming Architecture

LaunchKit uses the Vercel AI SDK's `streamText` and `streamObject` to pipe Gemini model responses directly to the client as they generate. The frontend uses `useStreamableValue` and custom typewriter animations to display output progressively, giving users immediate feedback without waiting for full completion.

### Prompt Engineering

The generation is split into separate prompts for each output section (landing page, Twitter, LinkedIn, Product Hunt, pitch), each with distinct tone and format instructions. A large landing page template in `lib/landing-template.ts` (26KB) guides the model toward production-quality marketing copy with specific structural requirements.

### GitHub README Parsing

When a GitHub URL is provided, LaunchKit fetches the repository's raw README content via the GitHub raw content API, strips Markdown formatting, and feeds the cleaned text as project context to the generation prompts. This enables high-quality output for existing projects without manual description.

### Design System

LaunchKit uses an editorial, high-contrast dark design aesthetic:
- Background: `#0a0a0a` (near-black)
- Accents: warm off-white `#e8e0d0` and muted ochre tones
- Typography: Playfair Display (serif headlines), DM Mono (body and code)
- UI: flat outlined buttons, dark inputs, sharp-cornered cards — no neon or gradients
- Motion: fade-up reveals on load, streaming typewriter text output
